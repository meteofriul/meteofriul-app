# Archivio della migrazione UI 3

Questi documenti conservano decisioni, audit e prove della migrazione dalla
precedente app alla base canonica. Possono contenere nomi di vecchie cartelle,
percorsi locali e comandi validi soltanto nel momento storico in cui furono
scritti.

Non sono istruzioni di avvio, dipendenze runtime o sorgenti da cui copiare
codice. Le procedure correnti sono `STARTUP_PROMPT.md`, `README.md`,
`AGENTS.md` e i runbook sotto `docs/operations/`.

L'archivio resta versionato per tracciabilita' e per spiegare le decisioni gia'
prese, ma non deve essere usato per individuare la cartella di lavoro.
